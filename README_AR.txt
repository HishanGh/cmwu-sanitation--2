تطبيق فريق الصرف الصحي — مشروع أندرويد (Capacitor)
=====================================================
الفكرة: نفس التطبيق داخل غلاف أندرويد أصلي. زر "مشاركة الملف مباشرة" يفتح قائمة المشاركة الأصلية (واتساب وغيره) بدون أي شروط، ويعمل التطبيق بدون إنترنت.

الطريقة 1 (بدون برامج على الكمبيوتر) — GitHub Actions
 1) أنشئ حسابًا مجانيًا على github.com ثم New repository واجعله Private.
 2) ارفع كل محتويات هذا المجلد (Add file > Upload files) — مهم رفع مجلد .github أيضًا.
    إن لم يظهر المجلد: أنشئ ملفًا بالمسار  .github/workflows/build-apk.yml  والصق محتوى الملف الموجود في المشروع.
 3) افتح تبويب Actions وانتظر انتهاء "Build APK" (نحو 5-8 دقائق).
 4) من صفحة التشغيل نزّل Artifact باسم CMWU-Sanitation-Team-APK وفك الضغط ستجد CMWU-Sanitation-Team.apk.
 5) أرسل الـ APK للفنيين، وعلى الجوال: افتحه وفعّل "السماح بالتثبيت من هذا المصدر".

الطريقة 2 — Android Studio على الكمبيوتر
 افتح مجلد android، ثم Build > Build Bundle(s)/APK(s) > Build APK(s).

ملاحظات مهمة
 - مفتاح التوقيع داخل المشروع: android/keystore. احتفظ به ولا تنشر المشروع علنًا. أي تحديث مستقبلي يجب أن يُوقَّع بنفس المفتاح حتى يُثبَّت فوق النسخة القديمة بدون حذف بياناتها.
 - لتعديل التطبيق: عدّل www/index.html ثم ارفع التعديل (أو شغّل Actions)، وغيّر versionCode في android/app/build.gradle (1 → 2 ...) لكل إصدار جديد.
 - خط Tajawal يُحمَّل من الإنترنت؛ بدون إنترنت يظهر خط النظام.
